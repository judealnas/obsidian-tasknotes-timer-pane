# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** The sidebar `ItemView` for Phase 1 (PANE-01..03, DISP-01..03, DISP-05, DISP-06, CTRL-01, SYNC-01..04). It has one running-timer card, a plain idle message, three TaskNotes-unavailable states, and one action (Stop).

**Out of scope for this phase** (do not build, do not reserve layout space):
- "Start a task" button and picker (DISP-04, CTRL-05/06, Phase 2)
- Complete (CTRL-07, Phase 2)
- Pause and resume (CTRL-02/03, Phase 3)
- Pomodoro label (DISP-07, Phase 3)
- Estimate progress (DISP-08, v2)
- "Also running" list with per-row stop (DISP-09, v2)

**Sources:** No phase CONTEXT.md or RESEARCH.md exists. Decisions below come from:
- REQUIREMENTS.md and ROADMAP.md Phase 1 success criteria
- `.planning/research/` (ARCHITECTURE Patterns 3, 5 and 6; FEATURES TS-1..TS-11; PITFALLS UX table)
- CLAUDE.md constraints
- Obsidian CSS variable docs (docs.obsidian.md: Typography, Spacing, Colors; fetched 2026-10-13)
- TaskNotes `styles/pomodoro-view.css` (look-and-feel reference; fetched 2026-10-13)

Items marked *(default)* are researcher defaults. The user was not asked about them.

## Design System

| Property | Value |
|----------|-------|
| Tool | none. Obsidian plugin with vanilla DOM in `ItemView`; shadcn does not apply (not React) |
| Preset | not applicable |
| Component library | none. Obsidian built-in classes only (`button`, `button.mod-cta`) plus plugin BEM classes in `styles.css` |
| Icon library | Lucide via Obsidian `setIcon()` (bundled with Obsidian; nothing to install) |
| Font | Inherited. `var(--font-interface)` for all UI text, `var(--font-monospace)` for the two time readouts |
| Theming rule | Every color, size, spacing, radius and font value in `styles.css` is an Obsidian CSS variable, or a `calc()` of one. **No hex, rgb or hsl literals.** The pane must look right in any community theme, light and dark |
| Styling rule | All styling lives in `styles.css`. No inline styles, no `el.style.*`, no `innerHTML` (eslint-plugin-obsidianmd). State changes toggle classes with `toggleClass()`. Text is set with `setText()` / `createEl({ text })` |
| Class prefix | `tntp-` (TaskNotes timer pane). Avoids clashes with TaskNotes' own `tasknotes-plugin`, `pomodoro-view__*` and `--tn-*` names |

**Icons used in this phase (closed set):**

| Icon id | Where |
|---------|-------|
| `timer` | Ribbon icon, and `getIcon()` for the view tab |
| `square` | Leading icon inside the Stop button (matches TaskNotes' status-bar stop glyph) |

Verify both ids at scaffold time. In the dev vault console, run `require("obsidian").getIconIds().filter(i => ["timer","square"].includes(i))`. It must return both. Message states have no icons.

This is not a component inventory (`Tool: none`). Verify each symbol once `obsidian@1.14.4` is installed:
`grep -nE "class ItemView|export function setIcon|export function setTooltip|class Notice|class Keymap|ensureSideLeaf|revealLeaf|openLinkText" node_modules/obsidian/obsidian.d.ts`

## Spacing Scale

Declared values (all multiples of 4, all mapped to Obsidian `--size-4-*` variables):

| Token | Value | CSS variable | Usage in this phase |
|-------|-------|--------------|---------------------|
| xs | 4px | `--size-4-1` | Label-to-value gap (e.g. "Session" above clock); gap between button icon and label (Obsidian default) |
| sm | 8px | `--size-4-2` | Status row to task title; "Total" label to value (inline gap); status dot to "Tracking" |
| md | 16px | `--size-4-4` | Pane padding (all sides); card padding (all sides); vertical gap between card groups (title, session, total, actions) |
| lg | 24px | `--size-4-6` | Top padding above message states (idle, loading, unavailable); gap between message body and "Check for TaskNotes" button |
| xl | 32px | `--size-4-8` | Not used in Phase 1. Reserved for Phase 2 section breaks |
| 2xl | 48px | `--size-4-12` | Not used in Phase 1 |
| 3xl | 64px | `--size-4-16` | Not used in Phase 1 |

Exceptions:
- Card border is `1px` (`var(--border-width)`), not a spacing token.
- Status dot is `8px` (`--size-4-2`) square with `border-radius: 50%`.
- Button height is not set. Inherit Obsidian's `--input-height` (desktop default 30px). Do not override padding on Obsidian buttons.
- Card corner radius is `var(--radius-m)`.
- Root content max-width is `480px`. This only matters if the user drags the pane into the main area. The sidebar width is normally 200 to 450px.

## Typography

Exactly four sizes and two weights. All values come from Obsidian variables, so they follow the user's interface font and zoom.

| Role | Size | CSS | Weight | Line height | Used for |
|------|------|-----|--------|-------------|----------|
| Label | 12px | `var(--font-ui-smaller)` | 400 (`--font-normal`) | 1.3 (`--line-height-tight`) | "Tracking", "Session", "Total", "+N more running", "Installed version: …". Color `--text-muted` |
| Body | 13px | `var(--font-ui-small)` | 400 (`--font-normal`) | 1.5 (`--line-height-normal`) | Message bodies, total time value, button labels (Obsidian button default) |
| Heading | 15px | `var(--font-ui-medium)` | 600 (`--font-semibold`) | 1.3 (`--line-height-tight`) | Task title; message-state headings |
| Display | 32px | `calc(var(--font-ui-large) * 1.6)` | 600 (`--font-semibold`) | 1.1 | Session clock only |

Numeric rules:
- **Session clock and total value** use `font-family: var(--font-monospace)` and `font-variant-numeric: tabular-nums`, so digits never shift as they tick.
- The session clock has `white-space: nowrap` and `letter-spacing: normal`.
- **Narrow-pane rule (Display role only):** `.tntp-card` sets `container-type: inline-size`, and the clock uses `font-size: min(calc(var(--font-ui-large) * 1.6), 17cqi)`. At normal sidebar widths the clock stays 32px. It shrinks proportionally only when the card's content box is narrower than about 190px, so `100:00:00` never clips or wraps. This is a fluid floor on the same role, not a fifth size. Do not add media queries or JS width classes.
- Labels are sentence case, not uppercase. Do not use `text-transform`.

**Time format (both readouts):** `H:MM:SS`. Hours are unpadded and unbounded; minutes and seconds are zero-padded. Examples: `0:00:07`, `0:42:17`, `12:03:00`, `105:12:03`. Negative values (clock skew, future `startTime`) clamp to `0:00:00`. Total uses the same format, to the second (DISP-03).

## Layout and Visual Hierarchy

**Focal point:** The session clock (Display, 32px semibold mono). It is the largest element in every running state. Reading order is: status row, then task title, then session clock, then total, then Stop.

**Alignment:** Left-aligned throughout (sidebar convention). The card fills the pane width, up to the 480px max-width.

### DOM structure (built once in `onOpen`, updated in place)

```

├─ div.tntp-card                          // shown only when --running
│  ├─ div.tntp-status                     // flex row, space-between, align center
│  │  ├─ span.tntp-status__live           // flex row, gap 8px
│  │  │  ├─ span.tntp-status__dot         // 8px accent dot
│  │  │  └─ span.tntp-label  "Tracking"
│  │  └─ span.tntp-label.tntp-status__more  "+2 more running"   // only when others > 0
│  ├─ div.tntp-title  role="link" tabindex="0"   // Heading role, wraps
│  ├─ div.tntp-stat.tntp-stat--session
│  │  ├─ span.tntp-label  "Session"
│  │  └─ span.tntp-clock  role="timer" aria-live="off"   "0:42:17"
│  ├─ div.tntp-stat.tntp-stat--total      // flex row, baseline, gap 8px
│  │  ├─ span.tntp-label  "Total"
```

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Ribbon icon click (`timer`, tooltip "Open TaskNotes timer") | Reveal the existing pane leaf if one exists. Otherwise create it in the right sidebar and reveal it. Never create a second leaf (PANE-01). Uncollapse the right sidebar if collapsed |
| Command "Open timer pane" | Same as ribbon (PANE-02) |
| Restart | Leaf restored in place by Obsidian's layout serialization. On restore, render immediately from current bridge state; never blank (PANE-03) |
| Task title click | `openLinkText(taskPath, "", Keymap.isModEvent(evt))`: plain click opens in the active main leaf; Ctrl/Cmd-click opens a new tab (DISP-01). Cursor `var(--cursor-link)`. Tooltip "Open task note" |
| Task title keyboard | Focusable (`tabindex="0"`). Enter or Space behaves like a plain click |
| Stop click | 1. Disable the button immediately and change its label to "Stopping…" (blocks double-clicks). 2. Call stop on the **displayed** task only (CTRL-01). 3. On success, await the store refresh; the pane then shows idle, or the next most recently started timer if others are running. 4. On failure, re-enable, restore "Stop timer", and show the failure Notice. A "no active session" error is a benign race: no Notice, just refresh |
| Stop confirmation | **None.** Stopping is one click (CTRL-01) and is not destructive: the time entry is closed and kept |
| Live tick | Every 1 s, update only the clock and total text nodes from `Date.now() - startTime` (DISP-02/03). No TaskNotes calls per tick. Skip DOM writes while `!contentEl.isShown()` |
| Becoming visible / window focus / `visibilitychange` to visible | Tick immediately and request a store refresh. The pane never shows a stale value for more than one tick after reveal or after sleep and wake (SYNC-04) |
| External change (status bar, task card, command, Sync, hand-edited YAML) | Pane reflects it within about 1 s (SYNC-01/02). **No transition animation and no idle flash:** keep the previous render until the refreshed snapshot arrives, then swap in one frame |
| Primary timer selection | With several open entries, the card shows the one with the latest `startTime` (DISP-06). Ties are broken by task path, ascending (stable, no flicker) |
| "+N more running" | Shown only when other open entries exist. Hover tooltip lists the other task titles (see Copywriting). Not clickable in Phase 1 |
| TaskNotes disabled/enabled/updated | Pane switches between message states and running/idle on its own. Triggers: bridge `state` event, 5 s probe, `onOpen`, and "Check for TaskNotes" (SYNC-03). The switch happens without an Obsidian restart |
| "Check for TaskNotes" click | Calls `bridge.probe()` immediately. No busy state (synchronous) |
| Animations | None in Phase 1. The ticking clock is the liveness cue. The status dot is static. This satisfies reduced-motion preferences by default |

**Accessibility:**
- The Stop button is a native `<button>` with visible text.
- The title has `role="link"` and an `aria-label` of `Open {title}`.
- The clock has `role="timer"` and `aria-live="off"`, so it does not announce every second.
- The message container has `aria-live="polite"`, so state changes (for example, "TaskNotes is not enabled") are announced once.
- All text uses theme text variables, so contrast is inherited from the theme.

## Copywriting Contract

All UI strings are sentence case (eslint-plugin-obsidianmd `ui/sentence-case`). "TaskNotes" is the only intentionally capitalized brand word. If the lint rule flags it, add `TaskNotes` to the rule's brand list; do not change the copy. Use the single-character ellipsis `…`.

| Element | Copy |
|---------|------|
| Primary CTA | **Stop timer** (busy: **Stopping…**) |
| View display text (`getDisplayText`) | TaskNotes timer |
| Ribbon tooltip | Open TaskNotes timer |
| Command name | Open timer pane |
| Status label (running) | Tracking |
| Other timers indicator | `+1 more running` / `+{n} more running` |
| Other timers tooltip | `Also running: {title1}, {title2}` (at most 5 titles, comma separated; if more, append `, and {k} more`) |
| Session label | Session |
| Total label | Total |
| Title tooltip | Open task note |
| Title fallback (empty `task.title`) | The task file's basename without `.md` |
| Empty state heading (idle, ready, no timers) | No task is being timed |
| Empty state body | Start time tracking on a task in TaskNotes and it will show up here. |
| Loading (bridge `loading`) | Body only, no heading: `Connecting to TaskNotes…` |
| Unavailable heading (bridge `missing`: not installed or disabled) | TaskNotes is not enabled |
| Unavailable body | This pane needs the TaskNotes plugin. Install or enable it in Settings → Community plugins, and the pane will connect on its own. |
| Incompatible heading (bridge `incompatible`: older than 4.10 or missing capability) | TaskNotes needs an update |
| Incompatible body | This pane needs TaskNotes 4.10 or later. Update it in Settings → Community plugins, and the pane will connect on its own. |
| Incompatible meta (only if installed version is readable) | `Installed version: {version}` |
| Retry button (missing and incompatible states) | Check for TaskNotes |
| Error state (Stop failed, `Notice`) | `Couldn't stop the timer for "{title}": {reason}. Try again, or stop it from the TaskNotes status bar.` `{reason}` is the normalized TaskNotes API error message. If it is empty, use `TaskNotes reported an error` |
| Destructive confirmation | None in this phase. Stop is non-destructive and must stay one click |

Copy rules:
- Never show raw error objects or stack traces in the UI.
- Never show the bridge state names (`missing`, `incompatible`, `loading`, `ready`).
- Titles are rendered as text, never as HTML or Markdown.
