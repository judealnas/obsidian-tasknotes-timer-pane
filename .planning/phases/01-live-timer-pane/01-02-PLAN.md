A. `src/tasknotes/TaskNotesBridge.ts`. Implement the Interfaces block exactly, importing the obsidian package only through type-only imports (the module must load under Vitest). `isVersionOlder(version, minimum)` compares dot-separated numeric segments left to right. It strips any "-prerelease" or "+build" suffix first and treats missing segments as 0. If either string has a non-numeric segment it returns false, so an unknown version means "loading", never a false "needs an update". `probe()` follows RESEARCH Pattern 1, inside a try/catch that logs the message, detaches, and sets missing:
  1. A null plugin detaches and sets missing.
  2. A plugin with no api detaches. It sets incompatible (with `plugin.manifest.version`) when `isVersionOlder(version, MIN_TASKNOTES_VERSION)`, otherwise loading.
  3. `api.apiVersion !== 1`, or any REQUIRED_CAPABILITIES entry failing `hasCapability`, detaches and sets incompatible.
  4. An api object different from the attached one: detach the old refs and attach the new one. Subscribe lifecycle "layout.ready" first (handler: `probe()`, then emit data), then events "task.updated" (handler: emit data). Store each unsubscribe as a closure over `api.lifecycle.off(ref)` / `api.events.off(ref)` in a private array. Never route TaskNotes refs through Obsidian's registerEvent (RESEARCH Pattern 1).
  5. The state is ready when `api.lifecycle.isReady()` returns true, otherwise loading. Never use the lifecycle readiness promise as the read gate (Pitfall 2).
  `setState` notifies onState listeners only when the kind or version changes. Each listener call is wrapped in try/catch, which logs. `active()` rejects with `new Error("TaskNotes is not connected")` unless an api is attached and the state is ready; otherwise it returns `api.time.active()`. `dispose()` detaches every ref (each `off` in its own try/catch) and clears listeners.

B. `src/model/timeMath.ts`. Pure, with only `import type` from the vendored types and the bridge. In this task implement `parseMs` (non-string or `Date.parse` NaN gives null), `sessionMs` (`Math.max(0, now - start)`), and `formatHms`. `formatHms` floors to whole seconds, maps negative or NaN to "0:00:00", leaves hours unpadded and unbounded, and zero-pads minutes and seconds, giving examples like 0:00:07, 0:42:17, 12:03:00 and 105:12:03. Also implement:
  - `OpenTimer` and `TimerSnapshot` exactly as in Interfaces. Leave `entries` empty in this task; Task 2 fills it.
  - `selectPrimary`: the latest startMs wins. A tie goes to the smaller `taskPath` by plain `<`, never a locale-aware comparison, so the choice is the same in every locale.
  - `deriveSnapshot`: drops any entry whose `entry.startTime` is missing or unparseable (this agrees with TaskNotes' status bar). Title is `task.title` trimmed. `archived` is `task?.archived === true`. Others are sorted by startMs descending, ties broken by path ascending. Treat every field of every ActiveTimeEntry as untrusted and use optional chaining.
  - `PaneState` and `derivePaneState`: missing gives "missing", incompatible gives "incompatible", loading gives "loading", ready with a null snapshot gives "loading", ready with a primary gives "running", and anything else gives "idle".

C. `src/state/TimerStore.ts`. Implement the Interfaces block with no value import of the obsidian package. The snapshot is null until the first successful refresh after the bridge reaches ready.
  - The constructor subscribes `gateway.onState`. Entering ready calls `requestRefresh()`. Leaving ready sets the snapshot to null and notifies.
  - It also subscribes `gateway.onData`, which calls `requestRefresh()`.
  - `requestRefresh()` delegates to `refreshNow()`. Plan 01-03 owns the 200 ms trailing debounce and the single-flight guard, behind this same method.
  - `refreshNow()` returns immediately unless the state is ready. Otherwise it awaits `gateway.active()`, sets `snapshot = deriveSnapshot(result)` and notifies. On rejection it logs only the error message and keeps the previous snapshot, with no retry scheduling.
  - `dispose()` removes both gateway subscriptions and all listeners.
