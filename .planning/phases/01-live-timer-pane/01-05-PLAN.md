<objective>
Add the write path to the skeleton (CTRL-01): a one-click "Stop timer" that stops only the displayed timer through `api.time.stop`. Also add the one automatic behavior decided for this phase (D-05..D-11): archived tasks' timers are stopped when, and only when, TaskNotes' own auto-stop setting is on, and are otherwise labelled "Archived".

Purpose: this proves the write half of the walking skeleton and keeps the user's tracked time safe. Every write goes through TaskNotes' lock and field mapping, carries a mutation context, and is serialized through one queue. Archived timers no longer keep running unseen when TaskNotes' setting says they should stop.
Output: `WriteQueue`, `TimerController`, `ArchiveAutoStopper`, `errors.ts`, and the bridge write and settings facade. The view gets the Stop button and the Archived label. New tests are `tests/controller.test.ts` and `tests/autoStop.test.ts`.
</objective>
