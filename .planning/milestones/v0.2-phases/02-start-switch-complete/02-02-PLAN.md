  <behavior>
    - Exact path and start-time equality to a live running unfinished/uninterrupted work session excludes only that entry; a same-path timer with another start time remains eligible.
    - No Pomodoro session makes all active regular timers eligible; unreadable or malformed ownership makes none writable.
    - Captured duplicate entries are stopped once in first-seen order, with a live active-timer and Pomodoro re-read immediately before each sequential call.
    - A vanished, replaced, or newly owned entry is skipped; a normal target failure is recorded and later targets continue; an ownership-read failure halts all remaining writes.
  </behavior>
  <action>
Implement pure `getPomodoroOwnedEntryId` and `selectRegularStopTargets` helpers around the canonical `(path,startTime)` identity. Ownership exists only for the exact D-03 work-session predicate: Pomodoro reports running, current session is work, neither completed nor interrupted, the normalized task paths match, and `timeTrackingStartTime` exactly equals the timer entry start time. Return an explicit unreadable result rather than treating an error or malformed response as no owner.

Add bridge accessors that bind the correct receiver and gate both `time.read`/`pomodoro.read` capability and callable shape. Implement `TimerController.stopAll()` as one `queue.run` callback per D-05: capture a finite, first-seen deduplicated list; before every target re-read active timers and Pomodoro status; skip a target that disappeared, changed identity, or is now owned; await one public path-only `time.stop` before moving to the next. Continue after ordinary target failures and aggregate safe feedback, but fail closed and halt remaining work if ownership cannot be read. Do not call another queued controller method from inside this callback.

Wire the existing Stop all header button to the controller and always release shared busy state in `finally`. Keep Notice/log text normalized and avoid task titles or paths in error messages. Record the unavoidable public path-only stop race in code comments and the task's human check; do not claim the pre-write read makes the write atomic.
